# Pocket Option Bot PRO

Αυτόματο bot συναλλαγών για την πλατφόρμα [Pocket Option](https://pocketoption.com), διανέμεται εδώ ως έτοιμα πακέτα εγκατάστασης — χωρίς αναμονή για έλεγχο στο Chrome Web Store, ενώ κάθε προηγούμενη έκδοση παραμένει διαθέσιμη.

- Ιστότοπος: https://2bot.top/el/
- Telegram (κανάλι ειδήσεων): https://t.me/PO_bot_news
- YouTube: https://www.youtube.com/@PocketOptionRobot
- Chrome Web Store: https://chromewebstore.google.com/detail/pocket-option-bot-pro/fgpcopnjkdcheolcfjlkcfifiphpakla

Έχετε πρόταση ή βρήκατε πρόβλημα; Αφήστε το στη [σελίδα επικοινωνίας του 2bot.top](https://2bot.top/el/contact/).

Αυτό το αποθετήριο δημοσιεύει έτοιμες για εγκατάσταση εκδόσεις της επέκτασης, ώστε να μπορείτε να εγκαταστήσετε νέες εκδόσεις πριν περάσουν τον έλεγχο του Chrome Web Store, και να κατεβάσετε πάντα μια παλαιότερη έκδοση αν χρειαστεί να επιστρέψετε πίσω. Δείτε το [CHANGELOG.md](CHANGELOG.md).

## Εγκατάσταση (χειροκίνητα, Λειτουργία προγραμματιστή)

Το Chrome εμποδίζει την απευθείας εγκατάσταση αρχείων `.crx` εκτός του Chrome Web Store, οπότε ο μόνος τρόπος να εγκαταστήσετε μια έκδοση από εδώ είναι φορτώνοντάς την ως **επέκταση χωρίς συσκευασία (unpacked)** σε Λειτουργία προγραμματιστή:

1. Μεταβείτε στη σελίδα [Releases](../../releases) και κατεβάστε το `.zip` της έκδοσης που θέλετε (η πρώτη είναι σημειωμένη ως **Latest**).
2. Αποσυμπιέστε το σε φάκελο που σκοπεύετε να διατηρήσετε στον δίσκο — μην διαγράψετε αυτόν τον φάκελο στη συνέχεια, καθώς το Chrome φορτώνει την επέκταση από εκεί κάθε φορά που ξεκινά ο περιηγητής.
3. Ανοίξτε το `chrome://extensions` στο Chrome (ή σε οποιονδήποτε περιηγητή βασισμένο σε Chromium).
4. Ενεργοποιήστε τη **Λειτουργία προγραμματιστή** (διακόπτης πάνω δεξιά).
5. Κάντε κλικ στο **Φόρτωση χωρίς συσκευασία (Load unpacked)** και επιλέξτε τον φάκελο που αποσυμπιέσατε στο βήμα 2.
6. Η επέκταση εμφανίζεται στη λίστα επεκτάσεών σας και ενεργοποιείται αυτόματα στο pocketoption.com και στα επίσημα κατοπτρικά του (mirrors).

### Ενημέρωση σε νέα έκδοση

Οι επεκτάσεις χωρίς συσκευασία που εγκαθίστανται με αυτόν τον τρόπο **δεν** ενημερώνονται αυτόματα. Για ενημέρωση:

1. Κατεβάστε και αποσυμπιέστε το `.zip` της νέας έκδοσης από τα [Releases](../../releases) σε **νέο** φάκελο (ή αντικαταστήστε τον παλιό).
2. Αν αντικαταστήσατε τον ίδιο φάκελο: ανοίξτε το `chrome://extensions` και κάντε κλικ στο εικονίδιο επαναφόρτωσης (↻) στην κάρτα της επέκτασης.
3. Αν χρησιμοποιήσατε νέο φάκελο: αφαιρέστε την παλιά καταχώρηση επέκτασης στο `chrome://extensions` και κάντε ξανά **Φόρτωση χωρίς συσκευασία** από τον νέο φάκελο.

### Επιστροφή σε προηγούμενη έκδοση

Κάθε δημοσιευμένη έκδοση παραμένει διαθέσιμη στη σελίδα [Releases](../../releases) — κατεβάστε το `.zip` της έκδοσης που χρειάζεστε και εγκαταστήστε το με τον ίδιο τρόπο.
