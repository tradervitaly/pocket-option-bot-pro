# Pocket Option Bot PRO

Bot trading otomatis untuk platform [Pocket Option](https://pocketoption.com), didistribusikan di sini sebagai build siap pasang — tanpa perlu menunggu peninjauan Chrome Web Store, dan setiap versi sebelumnya tetap tersedia.

- YouTube: https://www.youtube.com/@PocketOptionRobot
- Chrome Web Store: https://chromewebstore.google.com/detail/pocket-option-bot-pro/fgpcopnjkdcheolcfjlkcfifiphpakla

Punya saran atau menemukan masalah? Sampaikan di [halaman kontak 2bot.top](https://2bot.top/id/contact/).

Repositori ini menerbitkan versi ekstensi yang siap dipasang, sehingga Anda dapat memasang versi baru sebelum melalui peninjauan Chrome Web Store, dan selalu dapat mengunduh versi lama jika perlu kembali. Lihat [CHANGELOG.md](CHANGELOG.md).

## Pemasangan (manual, Mode Pengembang)

Chrome memblokir pemasangan langsung file `.crx` di luar Chrome Web Store, jadi satu-satunya cara memasang build dari sini adalah memuatnya sebagai **ekstensi tidak terkemas (unpacked)** dalam Mode Pengembang:

1. Buka halaman [Releases](../../releases) dan unduh `.zip` versi yang diinginkan (versi paling atas ditandai **Latest**).
2. Ekstrak ke folder yang ingin Anda simpan secara permanen di disk — jangan hapus folder ini setelahnya, Chrome memuat ekstensi dari sana setiap kali browser dimulai.
3. Buka `chrome://extensions` di Chrome (atau browser berbasis Chromium lainnya).
4. Aktifkan **Mode Pengembang** (sakelar di pojok kanan atas).
5. Klik **Muat yang belum dikemas (Load unpacked)** dan pilih folder yang diekstrak pada langkah 2.
6. Ekstensi akan muncul di daftar ekstensi Anda dan otomatis aktif di pocketoption.com serta mirror resminya.

### Memperbarui ke versi baru

Ekstensi tidak terkemas yang dipasang dengan cara ini **tidak** diperbarui secara otomatis. Untuk memperbarui:

1. Unduh dan ekstrak `.zip` versi baru dari [Releases](../../releases) ke folder **baru** (atau timpa folder lama).
2. Jika Anda menimpa folder yang sama: buka `chrome://extensions` dan klik ikon muat ulang (↻) pada kartu ekstensi.
3. Jika Anda menggunakan folder baru: hapus entri ekstensi lama di `chrome://extensions` dan klik lagi **Muat yang belum dikemas** dari folder baru.

### Kembali ke versi sebelumnya

Setiap versi yang diterbitkan tetap tersedia di halaman [Releases](../../releases) — unduh `.zip` versi yang Anda butuhkan dan pasang dengan cara yang sama.

## Penafian

Trading opsi biner memiliki risiko kerugian yang tinggi. Ekstensi ini adalah alat otomatisasi yang mengikuti aturan yang Anda konfigurasikan — bukan merupakan nasihat keuangan dan tidak menjamin keuntungan. Anda sepenuhnya bertanggung jawab atas keputusan trading Anda.
