# Pocket Option Bot PRO

Бот для автоматической торговли на платформе [Pocket Option](https://pocketoption.com), распространяемый здесь в виде готовых к установке сборок — без ожидания проверки в Chrome Web Store, при этом каждая предыдущая версия остаётся доступной.

- Сайт: https://2bot.top/ru/
- Telegram (канал новостей): https://t.me/PO_bot_news
- YouTube: https://www.youtube.com/@PocketOptionRobot
- Chrome Web Store: https://chromewebstore.google.com/detail/pocket-option-bot-pro/fgpcopnjkdcheolcfjlkcfifiphpakla

Есть предложение или нашли проблему? Оставьте её на [странице обратной связи 2bot.top](https://2bot.top/ru/contact/).

Этот репозиторий публикует готовые к установке версии расширения, так что вы можете установить новую версию ещё до того, как она пройдёт проверку в Chrome Web Store, и всегда можете скачать более старую версию, если понадобится откатиться назад. Историю версий смотрите в [CHANGELOG.md](CHANGELOG.md).

## Установка (вручную, режим разработчика)

Chrome блокирует прямую установку файлов `.crx` вне Chrome Web Store, поэтому единственный способ установить сборку отсюда — загрузить её как **распакованное расширение (unpacked)** в режиме разработчика:

1. Перейдите на страницу [Releases](../../releases) и скачайте `.zip` нужной версии (самая верхняя помечена как **Latest**).
2. Распакуйте его в папку, которую вы планируете сохранить на диске — не удаляйте эту папку впоследствии, Chrome загружает расширение из неё при каждом запуске браузера.
3. Откройте `chrome://extensions` в Chrome (или любом браузере на основе Chromium).
4. Включите **режим разработчика** (переключатель в правом верхнем углу).
5. Нажмите **Загрузить распакованное расширение (Load unpacked)** и выберите папку, распакованную на шаге 2.
6. Расширение появится в списке ваших расширений и автоматически активируется на pocketoption.com и его официальных зеркалах.

### Обновление до новой версии

Распакованные расширения, установленные таким способом, **не** обновляются автоматически. Чтобы обновить:

1. Скачайте и распакуйте `.zip` новой версии со страницы [Releases](../../releases) в **новую** папку (либо перезапишите старую).
2. Если вы перезаписали ту же папку: откройте `chrome://extensions` и нажмите значок перезагрузки (↻) на карточке расширения.
3. Если вы использовали новую папку: удалите старую запись расширения в `chrome://extensions` и снова нажмите **Загрузить распакованное расширение** из новой папки.

### Возврат к предыдущей версии

Каждая опубликованная версия остаётся доступной на странице [Releases](../../releases) — скачайте `.zip` нужной версии и установите её тем же способом.
