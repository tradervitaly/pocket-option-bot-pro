# Pocket Option Bot PRO

Bot dagangan automatik untuk platform [Pocket Option](https://pocketoption.com), diedarkan di sini sebagai binaan sedia pasang — tanpa perlu menunggu semakan Chrome Web Store, dan setiap versi sebelumnya kekal tersedia.

Ada cadangan atau menjumpai masalah? Tinggalkan di [halaman hubungi 2bot.top](https://2bot.top/ms/contact/).

Repositori ini menerbitkan versi sedia pasang bagi sambungan, jadi anda boleh memasang versi baharu sebelum ia melalui semakan Chrome Web Store, dan sentiasa boleh memuat turun versi lama jika perlu kembali semula. Lihat [CHANGELOG.md](CHANGELOG.md).

## Pemasangan (manual, Mod Pembangun)

Chrome menyekat pemasangan fail `.crx` secara terus di luar Chrome Web Store, jadi satu-satunya cara untuk memasang binaan dari sini ialah memuatkannya sebagai **sambungan tidak dibungkus (unpacked)** dalam Mod Pembangun:

1. Pergi ke halaman [Releases](../../releases) dan muat turun `.zip` versi yang anda mahu (yang teratas ditanda **Latest**).
2. Nyahzip ke dalam folder yang anda ingin simpan di cakera — jangan padam folder ini selepas itu, Chrome memuatkan sambungan daripadanya setiap kali pelayar dimulakan.
3. Buka `chrome://extensions` dalam Chrome (atau mana-mana pelayar berasaskan Chromium).
4. Hidupkan **Mod Pembangun** (suis di penjuru atas kanan).
5. Klik **Muatkan tanpa dibungkus (Load unpacked)** dan pilih folder yang dinyahzip pada langkah 2.
6. Sambungan akan muncul dalam senarai sambungan anda dan diaktifkan secara automatik pada pocketoption.com dan cermin rasminya.

### Mengemas kini ke versi baharu

Sambungan tidak dibungkus yang dipasang dengan cara ini **tidak** dikemas kini secara automatik. Untuk mengemas kini:

1. Muat turun dan nyahzip `.zip` versi baharu dari [Releases](../../releases) ke dalam folder **baharu** (atau timpa folder lama).
2. Jika anda menimpa folder yang sama: buka `chrome://extensions` dan klik ikon muat semula (↻) pada kad sambungan.
3. Jika anda menggunakan folder baharu: buang entri sambungan lama dalam `chrome://extensions` dan klik semula **Muatkan tanpa dibungkus** dari folder baharu.

### Kembali ke versi terdahulu

Setiap versi yang diterbitkan kekal tersedia di halaman [Releases](../../releases) — muat turun `.zip` versi yang anda perlukan dan pasang dengan cara yang sama.

## Penafian

Dagangan opsyen binari membawa risiko kerugian yang tinggi. Sambungan ini adalah alat automasi yang mengikut peraturan yang anda konfigurasikan — ia bukan nasihat kewangan dan tidak menjamin keuntungan. Anda bertanggungjawab sepenuhnya ke atas keputusan dagangan anda.
